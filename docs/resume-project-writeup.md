# TaskFlow 项目简历写作稿

## 1. 项目描述（可直接放简历）
TaskFlow 是一个基于 Next.js App Router + TypeScript 的个人任务管理系统，围绕“任务创建、筛选排序、截止预警、进度可视化、账号资料管理”构建完整闭环。项目接入 Supabase 实现认证与数据持久化，并通过本地演示模式实现无后端配置下的可运行体验；同时使用 URL 参数同步筛选条件与看板时间范围，保证页面状态可分享、可回放。

## 2. 主要工作（可直接放简历）
- 负责前端整体架构设计与落地：采用 Next.js App Router 分层组织页面、布局和路由。
- 完成认证链路开发：实现注册、登录、回调处理（code exchange + OTP verify），并在服务端布局与中间件层做会话校验。
- 设计并实现任务模块：支持任务创建、编辑、删除、状态流转、优先级管理、标签管理与任务详情页。
- 搭建多维筛选与排序体系：支持 query/tag/status/priority/sort 五维筛选，并与 URL 参数双向同步。
- 构建 Dashboard 数据视图：实现统计卡片、完成趋势、状态分布、标签分布、近期活动、即将到期提醒等模块。
- 设计截止日期风险算法：抽象任务到期元信息（逾期/今日到期/即将到期）并统一用于排序和视觉提示。
- 实现状态管理与数据同步：基于 Zustand + persist 管理任务状态，支持 Supabase 远程模式与本地模式自动切换。
- 完善工程与数据层：定义 Zod 表单校验规则、Supabase profiles/tasks 表结构、RLS 策略、自动时间戳触发器与索引。

## 3. 相关成果（可直接放简历）
- 形成了“认证 + 任务 + 看板 + 设置”的完整产品主流程，可用于个人作品集持续迭代。
- 建立了双模式运行能力（Supabase 真实数据 / localStorage 演示数据），降低了项目演示与部署门槛。
- 实现了可分享的页面状态机制：Dashboard 时间范围与任务筛选条件均可通过 URL 还原。
- 将业务规则组件化和工具化：任务排序、截止风险、标签解析等逻辑独立沉淀，便于复用与测试。
- 在数据库层引入 RLS 与触发器，确保用户数据隔离与任务时间字段自动维护。
- 采用严格 TypeScript 与统一表单校验，提升开发期类型安全与输入可靠性。

## 面向简历的精简版（1-2 行）
基于 Next.js + TypeScript + Supabase 独立开发个人任务管理系统 TaskFlow，完成认证、任务 CRUD、多维筛选、截止预警与仪表盘可视化，支持 URL 状态同步和本地/远程双模式数据运行。
