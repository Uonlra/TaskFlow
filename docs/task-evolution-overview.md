# 任务演进速览

总览的小型任务列表继续打开速览，日历复用同一组件。顶部任务名称即当前目标，下方显示完成标准、任务描述和状态。只显示一条待处理事项：优先展示目标变化后仍在推进的待检查分支，其次展示最近一份仍有未采纳条目的已提交结论。普通进展不会成为待采纳事项，搁置分支不提示采纳，已完成任务不显示决策提示。

有实际演进历史时展示最近五个关键节点。普通进展映射到关键行之间的虚拟位置，保留真实分支与汇入关系。点击节点就地查看原因、成果与目标变化，再进入完整详情定位原记录。没有分支时隐藏探索计数，只有起点时隐藏空演进图。

## 保存与读取

- 总览列表是摘要，打开速览时读取完整任务；读取前限制修改操作，错误时提供重试及完整详情入口。
- 读取按任务和账户隔离，迟到响应不能覆盖其他任务；展示优先保留更高演进版本和更新的任务内容。
- 速览支持记录主线进展，沿用版本检查、操作 ID、保存失败保留草稿与重试规则。成功后立即更新速览与 Store，再刷新总览或日历查询。
- 日历后续刷新失败时保留已保存结果及现有列表，并通过错误状态提供重试。
- 关闭时恢复入口焦点并保留原页面位置；若刷新替换了入口，通过任务标识寻找新的按钮。嵌套编辑、删除和节点详情保留各自的关闭边界，保存期间限制关闭和重复提交。

## 详情定位

`/tasks/:id` 支持 `event`、`branch`、`result` 和 `action` 查询参数。`action=adopt` 打开对应历史结论的采纳表单，`action=review` 打开分支检查表单；链接本身不会保存操作。普通记录链接展开指定节点，并将较早记录纳入显示和焦点定位。

详情核对当前状态：来源丢失、成果已全部采纳、分支已搁置或目标依据过期等情况不会自动打开不适用的采纳表单；无效定位退回正常详情。

## 验证与范围

回归覆盖完整任务补读、迟到响应、单条提示优先级、紧凑图连线、历史定位、保存失败重试、焦点恢复及日历刷新失败。浏览器验收使用访客样例。云端迁移及真实账户双端同步仍需按持久化说明执行；工作台关系摘要、完整方案比较和分支转独立任务仍是后续范围。
