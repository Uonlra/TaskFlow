# 桌面标题栏与快速记录

## 已确定的交互

- Windows 主窗口使用标题栏覆盖，保留系统窗口按钮；顶部应用菜单支持鼠标、Tab 和 F10。
- 顶部空白处用于拖动窗口，右侧提供快速记录入口；原有英文菜单栏不再常驻。
- 主窗口关闭仍然退出应用；独立快速记录窗口关闭只收起自身。
- 默认全局快捷键为 `Ctrl+Alt+N`，在设置的“快速记录”中可修改或关闭。应用退出后不再监听。
- 快速窗口预加载，重复唤起复用同一个窗口并聚焦标题；失焦不关闭。
- `Ctrl+Enter` 提交，输入法组合输入期间不提交；`Esc` 收起并保留本次运行期间的草稿。提供清空草稿操作。
- 本地写入成功才清空表单并收起；失败保留内容。工作区切换后需明确确认草稿归属。

## 实现边界

- `electron/desktop-controls.cjs` 管理窗口、原生菜单、快捷键注册和相关 IPC。
- 快捷键设置保存在当前 Electron userData 下的 `desktop-controls.json`。修改时先尝试注册新组合，冲突或保存失败时保留旧注册。
- 快速创建调用既有 `createLocalTask`，沿用 SQLCipher 数据库、工作区校验和同步队列。没有新的任务存储。
- 快速窗口不挂载 AuthProvider，避免第二个窗口并行执行云同步。主窗口继续使用既有同步机制。
- 创建完成通过主进程事件刷新主窗口的本地任务列表。新桌面控制 IPC 校验窗口身份、主 frame 和来源。
- 网页端不显示标题栏或快捷键设置，直接访问快速记录路由会给出桌面入口提示。

## 验证与本地复现

日常预览执行 `pnpm desktop:preview`，自动使用 `dist/preview-profile` 保存独立预览数据。首次缺少内置界面时自动构建；修改前端后执行 `pnpm desktop:preview --rebuild` 重新构建并打开。关闭主窗口即退出预览，再次运行会保留预览数据。

```powershell
pnpm desktop:web-build
$env:TASKFLOW_CONTROLS_ELECTRON_EXE = 'D:\path\to\electron.exe'
pnpm desktop:smoke:controls
```

运行时应使用与项目匹配的 Electron 45.1.0。脚本为每次运行创建独立的 `dist/controls-smoke-<时间>/profile`，不使用已安装应用或真实用户数据。报告与截图写入同级目录。

自动化覆盖原生窗口覆盖层、最大化/恢复、快速记录焦点、草稿保留、离线本地写入、主窗口刷新、快捷键冲突、禁用与重启持久化、错误工作区/窗口的 IPC 拒绝、主窗口退出，以及另一个独立进程持有焦点时的真实 Windows 快捷键唤起。

发布前仍需人工检查不同显示缩放、多屏拖动、标题栏双击、Alt+Space 系统菜单和 Windows 11 贴靠布局。此功能不修改版本号，不执行签名或发布流程。
