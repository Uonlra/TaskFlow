# 手动云端同步

2026-11-25 为降低持续请求和 Vercel CPU 消耗，桌面端改为手动更新云端。

- 启动、登录、恢复网络、普通页面加载和本地刷新不上传、不拉取云端任务。启动使用已加密保存的账户资料，不额外请求云端会话校验；云端权限仍在用户主动操作时由服务端核验。
- 本地编辑继续自动保存到加密 SQLite，并保留待同步队列。已有云端连接也遵循手动模式，不需要迁移或清空数据。
- 在设置中“连接云端账户”只绑定本地工作区。点击设置面板或 Windows 标题栏的“立即同步”，才分批上传积压操作、拉取云端任务并更新本地。
- 同步过程共享忙碌状态，相同账户的重复触发复用同一次操作。每次最多处理 20 批上传；仍有待上传内容时明确提示再次手动同步。同步完成后刷新当前任务详情，包含云端删除的情况。
- 失败不自动重试，保留本地任务和待同步操作；部分失败明确反馈。退出、切换账户或断开连接后，不将迟到响应导入另一个账户。已有冲突处理入口继续可用。
- 网页保留用户访问页面所需的读取和主动保存；移除登录恢复、侧栏趋势以及任务详情额外触发的全量列表读取。统计读取失败后只在用户点击“重新加载”时重试。
- Proxy 仅匹配 `/api/:path*` 和 `/settings/:path*`，保留 API 鉴权、跨域预检、来源校验及设置页保护，普通页面不再多执行一次前置函数。

应用程序版本检查访问 GitHub，与 Vercel 任务同步独立，本轮保持原有机制。

## 验证与生效

测试覆盖桌面启动与联网无同步请求、手动批次、重复点击、失败保留、账户隔离和 Proxy 匹配范围。`test/e2e/desktop-manual-sync.spec.ts` 使用隔离的模拟桌面桥和模拟 API，验证连接、手动上传下载和失败反馈，不访问真实云端账户。

本轮 84 个测试文件、473 项应用测试通过；手动同步浏览器回归及桌面静态构建通过。运行时检查使用本地候选服务与模拟账户，验证设置和标题栏入口。

真实云端验收脚本已改为点击“立即同步”，本轮不运行真实云端回归，避免继续消耗已暂停环境的额度。

网页修改需部署后生效，桌面修改需更新桌面应用。旧桌面版本仍可能按原逻辑轮询；更新前可在旧版设置中暂停云同步。修改不会清空 Vercel 已累计用量，也不自动解除平台暂停。
