# 关联任务入口与页面更新

来源及独立任务入口沿用原有简洁链接，在激活时检查目标，不为每个列表关系预先读取任务。覆盖详情侧栏、转出节点、方案对比和工作台关系。

## 不可访问的目标

- 当前工作区找不到目标时，在原链接旁显示“未找到关联任务”，保留当时的名称、转出事实和当前页面。
- 网络或服务失败显示“暂时无法读取”；认证失效显示“登录后可查看”；明确的权限拒绝显示“暂无访问权限”。重试会重新读取，不把网络失败缓存成删除状态。
- 桌面已经开启同步、账户仍匹配，但尚未收到关联任务时，可读取并导入云端已有目标，再进入详情。不会自动开启暂停的同步，也不会创建、复活或解除关联任务。
- 访客入口只查询当前访客工作区。备份中冻结的关系仍显示备份来源，不打开旧工作区的目标。
- 组件卸载、目标变化或账户切换会取消旧读取；迟到响应不触发导航。按住修饰键打开新标签页时保留链接的标准浏览器行为。

## 精确定位与页面一致性

网页及静态桌面共用演进目标参数解析，传递事件、分支、成果及允许的检查/采纳意图。来源入口返回具体转出节点，而不只打开来源任务。修复了静态桌面详情未传入这些参数的问题。

工作台根据同一账户 Store 中的保存版本核对页面成员和计数；新独立任务即使不在旧分页或筛选结果中，也会触发一次重新读取。重新读取失败保留已保存的记录，不反复请求同一份版本。日历接收同账户的转出通知并重新读取；其他账户的通知不会影响当前视图。桌面及访客的列表、总览和日历继续从 Store 派生。

## 验证

应用测试覆盖激活时读取、具体节点地址、找不到目标、网络/认证/权限失败、重试、账户切换后的迟到响应、尚未下载的桌面目标、暂停同步、删除快照及旧分页外的新任务计数。

真实账户与源码桌面已走通“独立任务 → 来源转出节点 → 独立任务”，并检查删除目标后的原地反馈、断网重试和恢复联网后的重新判断。来源历史不会被检查入口修改。
