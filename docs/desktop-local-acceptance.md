# 桌面端本地优先验收（更新于 2026-11-05）

桌面端默认使用加密的本地工作区，首次运行无需联网或登录。登录不会上传任务；设置页主动开启云同步后才加入云端账户。退出登录、暂停同步会保留当前工作区和本地编辑；切换账户使用独立工作区。

## 已验证

- 全新隔离用户目录，未登录、未开启同步，不请求云端 API。
- 模拟断网下创建、编辑、完成、删除任务。
- 正常关闭或首次保存后强制结束进程，重新启动均可恢复任务内容和完成状态。
- 总览、任务、任务详情、日历、统计、设置从本地资源加载。
- 本地任务在开启同步前没有上传队列；主动连接后加入对应账户队列。
- 暂停后仍可编辑；连接另一个账户不会带入前一个账户的任务。
- 任务页现有 JSON 导入、导出入口用于备份与迁移。

运行 `node scripts/smoke-desktop-local.mjs`（强制退出场景加 `--force-exit`） 可复测打包程序的离线操作和正常重启。需先生成 `dist/electron/win-unpacked/TaskFlow.exe`；脚本创建独立用户目录，不使用日常账户。

## 打包程序模拟云同步验收（2026-11-05）

运行 `pnpm desktop:smoke:sync`，或 `node scripts/smoke-desktop-sync.mjs <TaskFlow.exe 路径>`。测试使用独立数据目录、随机调试端口和虚构账户，拦截 HTTP/HTTPS 请求；进程使用不可达代理，防止拦截安装前访问真实服务。不会读取日常登录信息，不需要 Appwrite 密钥或真实密码。

本轮在现有 Windows x64 打包程序（应用版本 2.1.1）中验证：

- 从登录表单登录后不会自动上传本地任务；设置中主动开启同步后才上传并确认队列。
- 服务返回 503 时保留操作及重试次数；关闭程序后断网重启，恢复加密保存的身份、本地修改和同一条待同步操作。
- 恢复网络并触发在线事件后，由应用实际同步逻辑回放队列并确认云端完成状态。
- 云端新增任务通过远程仓库拉取到本地数据库。
- 暂停同步后仍可编辑并保留队列，恢复同步后回放。
- 删除任务回放到云端后清除待同步操作。
- 通过账户菜单退出登录保留本地任务，切换另一账户不携带原账户任务，重新连接原账户恢复其工作区。

测试驱动真实打包前端、IPC、加密数据库和队列回放逻辑，云端响应由内存模拟服务提供。它不验证生产 Appwrite 权限、真实 Cookie 跨域会话、生产冲突处理或安装升级；不能替代下一节的真实账户验收。脚本失败以非零状态退出，隔离数据保留在 `dist/electron/sync-smoke-*`，便于排查。

## 发布前仍需完成

Windows 隔离安装、覆盖升级和默认卸载后重装恢复已于 2026-11-05 验证通过，详见 [Windows 安装与数据保留验收](./desktop-install-acceptance.md)。该测试使用当前源码生成的两个版本，不替代实际旧版本数据库迁移和正式安装向导的人工验证。

- 云端删除和分页修复已通过“候选程序 + 本机候选 API + 真实 Appwrite”验收，包括 105 条任务分页与删除冲突。新 API 尚未部署，仍需上线后重跑生产验收，并补真实跨账户检查，详见 [真实云同步验收](./desktop-cloud-acceptance.md)。
- 已为 Electron 45 的 Windows 异步密钥增加首次落盘等待，超时停止数据库初始化且不清除数据。首次打开可能多等数秒。升级 Electron 时必须重跑强制退出验收，确认其安全存储格式仍兼容；之前已经丢失的系统密钥无法由此自动恢复。
- Windows 安装包仍未签名，使用默认图标；目前用于内部验收。
- Web 开发环境仍会偶发工具栏时钟跨分钟引起的 hydration 警告。
