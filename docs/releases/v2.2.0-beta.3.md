# TaskFlow 2.2.0-beta.3 · Windows x64 候选

本版将桌面云端同步改为手动操作，减少持续请求。当前仅准备本地候选安装包，没有创建或公开 GitHub Release。

- 启动、登录、恢复网络和后台闲置不再自动拉取或上传任务。
- 本地任务继续自动加密保存；在设置或标题栏点击“立即同步”才更新云端。
- 同步失败保留本地数据和待同步队列，等待用户手动重试。
- 增加探索、成果采纳、目标调整及 Git 风格演进记录，支持方案比较和分支转为独立任务。
- 改进同步冲突恢复、关联入口、长历史读取和窄屏呈现。

已有云端连接在升级后保留，行为统一改为手动同步。旧版更新前可先在设置中暂停云同步。新版不会清空 Vercel 已累计用量或自动解除平台暂停。

安装包：`TaskFlow-Setup-2.2.0-beta.3-win-x64.exe`，使用同目录 `SHA256SUMS.txt` 核对文件。沿用现有未签名 beta 构建配置；没有更改稳定版签名或公开发布策略。

真实 beta.2 程序到 beta.3 的隔离安装升级与模拟云端验收已通过，包括数据保留、120 秒无自动请求、手动上传下载及失败后重启恢复。详见[验收记录](../desktop-manual-upgrade-acceptance.md)；这不代表真实 GitHub 自动更新或生产云端验收完成。
