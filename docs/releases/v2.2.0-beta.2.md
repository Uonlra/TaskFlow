# TaskFlow 2.2.0-beta.2 · Windows x64

本版用于验收已发布的 beta.1 通过真实 GitHub 更新源升级到后续版本。本地任务功能和数据格式沿用 beta.1，没有新增数据库迁移。

## 本版变更

- 版本递增为 2.2.0-beta.2，供 beta.1 用户验证更新发现、下载和确认后重启安装。
- 仓库增加公开发布物验证命令，检查 GitHub 更新源、附件、版本和文件校验值。
- 补充真实升级及数据保留验收步骤；该检查工具不包含在桌面安装包中。

## 安装和升级

beta.1 用户可在本版公开后进入设置 → 应用更新 → 检查更新，手动下载，确认后重启安装。普通退出不会自动安装更新。

旧版 2.1.1 尚无更新器，需要手动下载安装包。覆盖安装和默认卸载保留当前 Windows 用户的本地数据；升级前建议导出任务 JSON 备份。

安装包为 `TaskFlow-Setup-2.2.0-beta.2-win-x64.exe`，可以使用同页 `SHA256SUMS.txt` 校验。本版仍为未签名 Windows x64 测试版，Windows 可能显示未知发布者或安全提示。请仅从本仓库下载，文件哈希不等同于发布者身份验证。

## 验收与限制

草稿不会被更新器发现。beta.1 → beta.2 的真实 GitHub 升级结果须在本版公开后记录，准备候选包不代表该项验收已通过。

beta 与正式通道隔离。macOS、Linux、ARM64 以及第二个真实云账户的隔离验收仍不在本轮范围内。
