# TaskFlow 2.2.0-beta.1 · Windows x64

首个提供自动更新入口的桌面测试版。测试期间建议定期通过任务页导出 JSON 备份。

## 本版功能

- 无需登录即可使用本地加密工作区，断网仍可启动、创建、编辑、完成和删除任务。
- 云同步可选：主动开启后同步任务，支持断网队列回放、跨设备删除和按最后更新时间解决冲突。
- 设置页新增应用更新：自动检查、手动下载、确认后重启安装；正常退出不自动安装。
- beta 通道与正式版隔离，禁止自动降级；beta 用户后续可升级到更新的正式版。

## 安装和升级

下载 `TaskFlow-Setup-2.2.0-beta.1-win-x64.exe`，可用同页 `SHA256SUMS.txt` 核对文件完整性。

此前 2.1.1 安装包未接入自动更新，需要手动安装本版一次；请正常关闭旧程序后安装。覆盖安装和默认卸载会保留此 Windows 用户的本地数据。更换电脑或 Windows 用户时，请使用任务页导出、导入迁移。

本测试版未配置 Windows 代码签名，Windows 可能显示未知发布者或安全提示。请从本仓库 Releases 下载并核对文件；文件哈希校验不等同于发布者身份验证。

## 测试范围与已知限制

- 首版只提供 Windows x64；macOS、Linux、ARM64 暂未提供。
- 更新需访问 GitHub Releases，网络不可用时可以继续本地使用。应用只读取已公开发布的更新，Release 草稿不会被客户端发现。
- 删除记录暂不自动过期，以支持长期离线设备的同步。
- 跨真实账户隔离仍需第二专用账户补充验收；本版已有模拟隔离及真实账户不匹配拒绝检查。
- 自动更新功能、数据保留及校验结果请以仓库验收记录为准。该版本为预发布测试版。
