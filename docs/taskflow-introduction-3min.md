# TaskFlow 项目介绍讲稿

> 面向没有编程和开源经验的听众；预计时长约 3 分钟。

大家好，今天我想介绍一个开源项目，叫 **TaskFlow**。它是一款个人任务管理工具，帮助我们整理学习、工作和生活中的各种安排。

事情一多，我们容易忘记截止时间，也容易忙了半天，却说不清推进了多少。TaskFlow 希望帮助大家看清三个问题：**今天该做什么，哪些事情更紧急，以及整体进展如何。**

这个项目，我想重点介绍三个亮点。

**第一个亮点，是丰富的可视化模块。** 项目中有完成进度环、任务趋势图、状态和优先级分布图，以及任务日历。进度环展示完成了多少，趋势图呈现近期的推进情况，日历则能看出任务集中在哪些日期。通过这些画面，用户可以快速了解自己的安排和进展。

**第二个亮点，是图表与任务操作的联动。** 比如，点击优先级分布图中“高优先级”的部分，就能查看对应任务；临近截止和已经逾期的事项，也会在页面上突出显示。用户看清情况以后，就能接着处理需要关注的事情。

**第三个亮点，是桌面端的离线能力。** 目前桌面端已经支持将任务加密保存在本机，没有网络也能创建、修改、完成和删除任务，重新打开应用后仍能继续使用。

技术上，项目用 **React 和 Next.js** 搭建网页应用，用 **TypeScript** 帮助减少开发中的代码错误；**ECharts** 负责绘制趋势和分布图，**Appwrite** 提供账户和云端数据服务。桌面端采用 **Electron**，把网页技术带到电脑应用中，并通过 **SQLite** 数据库保存本地任务。

目前，项目正从网页产品向桌面端和移动端推进，持续完善不同设备上的操作方式和使用体验。

未来，我希望把 TaskFlow 做成一个**能够根据指令执行操作的 AI 助手**。比如，你说：“帮我添加周五交报告的任务，设为高优先级。”它就能完成创建，也能按要求修改时间、删除取消的安排，并结合截止日期和完成情况提醒任务进度。这是项目接下来希望实现的方向。

开源意味着项目的源代码公开，大家可以了解它的实现、提出建议，也可以参与改进。

我希望 TaskFlow 能让我们少花一些精力记住事情、整理事情，把更多时间用在真正完成事情上。谢谢大家！
