# Git 式任务演进图

## 入口与呈现

任务详情页的“演进记录”已替换为左侧图、右侧事件列表。主线固定在最左侧，探索分支向右展开，最新记录显示在上方。事件标题优先显示操作及具体内容，次行显示来源，时间位于右侧。只用少量路径色，状态同时以文字和符号表达。

使用 [D3 Shape](https://d3js.org/d3-shape) 的 `line` 和 `curveBumpY` 生成 SVG 路径。布局与业务关系由纯函数计算，React 管理事件按钮、选择状态和详情，不引入画布拖拽或编辑工具栏。

界面采用视觉引导：移除操作教程、底部图例和重复副标题，工具栏与关闭使用图标，记录总数使用数字徽标，折叠行使用箭头与数量。保留业务内容、状态和必要的操作名称；图标仍提供悬停提示及屏幕阅读器名称。

桌面端占据左侧弹性主区域，右侧为固定约 300px 的目标与探索操作栏；任务属性收在右上角面板。标题、记录数量与选中态突出主区域，顶部标题和右侧按钮保持较低的视觉权重。演进列表按视口高度显示，打开节点详情后缩短列表，让所选记录与详情保持上下对应。窄屏切换为上下布局，并优先显示演进记录；DOM 与视觉顺序一致。

## 关系规则

- 事件按 `revision` 排序；相同时间戳或设备时钟回退不改变顺序。
- 分支从真实的 `originEventId` 派生。分支轨道按占用区间分配，只有互不重叠的区间才能复用；区间涵盖后续恢复或采纳，避免错误串线。
- 采纳的汇入线从该次引用的 `resultId` 出发。旧结论可多次汇入，后续结论及进展不会替换既有来源。汇入线在分支轨道旁绕行，避免穿过较新的成果节点。
- 采纳使用双圈节点。撤回后保留原汇入线并显示弱化虚线，原采纳和撤回事件均保留。
- 搁置与结束具有独立标记，不绘制汇入主线的假连接；仍在探索的分支保留延续线。
- 普通进展和步骤默认折叠为提示行。折叠仅隐藏文字行，布局仍保留真实连接；分页边界直接裁切真实路径，不把历史起点挪到可视区域。

## 交互

点击节点所在位置或整条记录打开下方节点详情，查看原因、具体成果条目和目标变更前后内容。采纳详情可定位到对应历史结论；撤回详情可定位原采纳；有来源分支时可跳转并聚焦“目标与探索”区域。有效采纳继续使用现有撤回表单保存操作。

“突出分支”及悬停弱化其他分支而保留主线。列表支持方向键上下、Home/End，向右打开详情并聚焦标题；详情中按 Escape 或点击关闭后恢复原记录焦点。加载更早记录时聚焦第一条新增记录；切换折叠模式时保留已选择的旧记录。切换不同任务后清除之前任务的选择和分支突出状态。

每批显示 30 行，普通进展可单段展开或全部展开。`compact` 模式已接入总览与日历速览，显示最近五个关键节点；普通进展映射到关键行之间的虚拟位置，保持路径连续，并隐藏完整视图工具。小于等于 700px 时切换为 72px 行高的纵向时间线，保留事件、状态、来源和时间，避免分支图挤占正文。主题沿用项目变量，并提供深色路径配色。

## 实现位置

- `src/features/tasks/utils/task-evolution-graph.ts`：拓扑、轨道、折叠及路径投影。
- `src/features/tasks/components/task-evolution-graph.tsx`：交互列表、SVG 与详情入口。
- `src/features/tasks/components/task-evolution-event-details.tsx`：历史事件内容、实际成果与目标变化。
- `src/features/tasks/utils/task-evolution-presentation.ts`：事件摘要与状态标签。
- `src/styles/task-evolution-graph.css`：布局、主题和窄屏样式。
- `test/fixtures/task-evolution.ts`：并行探索、部分采纳、撤回及轨道复用验收样例。

## 验证与边界

单元与组件测试覆盖拓扑、多次采纳、结束后采纳、分支恢复、折叠与分页、精确结论定位、撤回追溯、分支突出、任务切换及键盘焦点。真实浏览器使用访客存储导入隔离样例，确认节点与事件行中心对齐、同一旧结论两次汇入、定位来源结论及 390px 窄屏无页面横向溢出，并检查浅色与深色主题。

“加载更早记录”控制客户端渲染数量，当前仍一次读取单任务完整快照。快照沿用现有 1,000,000 UTF-8 字节上限；服务端游标分页和事件拆表尚未实现。此次未改变持久化与同步协议，云端迁移及真实双端同步验收仍需按持久化说明另行执行。
