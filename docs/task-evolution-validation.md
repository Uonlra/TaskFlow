## 重复执行

本机配置专用测试账户 `TASKFLOW_E2E_EMAIL`、`TASKFLOW_E2E_PASSWORD` 及现有 Appwrite 环境变量；不在日志或报告中写入密码、Cookie、会话密钥。先准备目标数据库，再启动本地候选服务，并为桌面验收构建指定相同 API：

```powershell
pnpm appwrite:ensure-task-evolution
pnpm dev -- --hostname 127.0.0.1 --port 3000
```

另一个终端中运行：

```powershell
$env:NEXT_PUBLIC_API_BASE_URL = 'http://127.0.0.1:3000'
pnpm desktop:web-build
pnpm desktop:smoke:evolution-cloud
Remove-Item Env:NEXT_PUBLIC_API_BASE_URL
```

脚本运行当前源码的 Electron 与 SQLite，并使用真实 Appwrite 用户会话；不会部署服务。只清理本轮创建且名称前缀及 ID 匹配的测试任务。若失败，报告仍会保存步骤、清理结果及未清理 ID；修复后应重新运行至全部通过。
