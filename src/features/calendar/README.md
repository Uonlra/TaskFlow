# 日历模块

- `components/calendar-client.tsx`：读取 URL 日期与抽屉状态、组织页面展示、提供操作反馈。
- `hooks/use-calendar-tasks.ts`：提供任务、提醒数量、加载状态、重试和任务操作。
- `utils/calendar-task-summary.ts`：纯函数形式的每日汇总。

访客任务直接派生自任务 Store；账户日历数据通过 `RemoteTaskRepository.listByDueRange` 加载。
创建、编辑、完成和删除统一调用 Store 的任务操作，使已加载的其他页面也能获得更新，再刷新日历查询。

账户查询以用户 ID 和日期范围区分。切换月份、切换账户或卸载时取消旧请求，并忽略迟到的响应。
任务保存期间切换月份时，旧操作完成后不会重新加载旧月份。

任务操作抛出异常表示保存失败；返回 `false` 表示保存已完成，但查询刷新失败或已被后续查询取代。
页面分别展示保存失败和保存成功但刷新失败的反馈，避免误导用户重复提交。
