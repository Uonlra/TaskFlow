# Report Formats

Pick the smallest format that fits the user's audience and amount of source material.

## Standard Chinese Weekly Report

```md
本周完成
- 完成……
- 推进……

进行中
- 正在……

风险 / 阻塞
- 存在……

下周计划
- 计划……
```

## Brief Chinese Manager Update

```md
本周重点
- …

当前风险
- …

下周目标
- …
```

## Project-Based Weekly Report

```md
项目 A
- 完成：
- 进行中：
- 风险：

项目 B
- 完成：
- 进行中：
- 风险：
```

## English Weekly Status Update

```md
Completed This Week
- ...

In Progress
- ...

Risks / Blockers
- ...

Plan for Next Week
- ...
```

## Source Normalization Tips

- Merge repetitive task logs into one outcome-focused bullet.
- Keep metrics and deadlines if the source includes them.
- If the input only lists activities, rewrite them into progress statements instead of raw logs.
